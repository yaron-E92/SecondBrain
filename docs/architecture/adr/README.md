# Architecture Decision Records

`docs/architecture/adr` is the canonical location for SecondBrain Architecture
Decision Records (ADRs). Architecture references must link to records in this
directory rather than create or use a parallel decision tree.

ADRs are numbered sequentially and are not renumbered after they are accepted or
superseded. Files use the `NNNN-short-title.md` naming convention.

Each ADR uses the following sections:

- Status
- Context
- Decision
- Consequences
- Alternatives considered
- Follow-up decisions
